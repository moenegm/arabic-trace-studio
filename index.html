Arabic Trace Studio

Draw each letter exactly as you want it traced. The tool records the raw points and the order of every stroke.

Saved locally

Use Apple Pencil, finger, or mouse. Each pen-down is saved as a separate stroke; dots are separate ordered marks.

Letters / shapes

Paste one item per line, up to 200 or more. Existing drawings with matching labels are retained.

Save and export

Your work autosaves in this browser. Export the project JSON as your editable backup; the Swift export contains normalized coordinates in the recorded motion order.

Compact Swift skips points within this distance of the drawn line. The raw JSON always keeps every captured point, and the preview toggle compares both paths.

Coordinates use a 0–1 range with origin at the top left. No point simplification or smoothing is applied.
